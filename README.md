# NEON STRIKE v3 (Tactical Clean Edition) 🔫
Three.js 기반의 3D 사이버펑크/SF FPS 게임

## 🎨 v3 비주얼 디자인 전면 개편 (눈 편한 에디션)
1. **눈이 편안한 컬러 팔레트**: 눈 찌르는 핫핑크/형광 사이언을 제거하고 차분한 딥 네이비, 슬레이트 그레이, 소프트 민트/스틸블루 포인트 적용
2. **배경 & 안개(Fog)**: 칠흑 같은 암흑 대신 깊이감 있는 네이비 배경과 부드러운 안개로 원경 블렌딩
3. **바닥 & 엄폐물**: 어지러운 고대비 네온 격자선을 완전히 없애고 은은한 콘크리트/메탈 패널 질감으로 교체
4. **UI & HUD**: 눈 시린 발광 효과를 빼고 세련된 반투명 다크 글래스모피즘(다크 슬레이트 + 쿨 화이트/민트 텍스트) 적용

## 🎮 주요 게임 시스템
- **로비 화면 & 설정**: 조준 감도 슬라이더, BGM/SFX 볼륨, 음소거, 최고 기록 저장
- **무기 해금 시스템**:
  - 1번 라이플 (기본)
  - 2번 샷건 (웨이브 3 달성 시 해금)
  - 3번 수류탄 (웨이브 5 달성 시 해금)
  - 4번 저격총 (웨이브 7 달성 시 해금, 우클릭/ZOOM 버튼으로 조준경 확대)
- **밸런스 패치**: 플레이어 체력 150, 적 공격력 및 탄속 완화, 웨이브 클리어 시 체력 대폭 회복

## 🕹️ 조작법
### PC
- **이동**: `W`, `A`, `S`, `D`
- **조준**: 마우스 이동 (클릭 시 마우스 고정)
- **발사**: 마우스 좌클릭
- **조준경(저격총)**: 마우스 우클릭 유지
- **점프**: `Space`
- **장전**: `R`
- **무기 교체**: `1`, `2`, `3`, `4`

### 모바일 (가로 화면 권장)
- **이동**: 화면 좌측 가상 조이스틱
- **조준**: 화면 우측 터치 드래그
- **사격 / 점프 / 장전 / ZOOM**: 화면 우측 가상 버튼
- **무기 교체**: 화면 상단 무기 버튼
