# NEON STRIKE 🔫
Three.js 기반의 3D 사이버펑크 네온 FPS 게임

## 🎮 게임 소개
네온 아레나에서 몰려오는 적 로봇과 자폭 드론을 무찌르는 웨이브 생존형 3D FPS 게임입니다.

### 🕹️ 조작법
#### PC
- **이동**: `W`, `A`, `S`, `D`
- **조준**: 마우스 이동 (화면 클릭 시 마우스 고정)
- **발사**: 마우스 좌클릭
- **점프**: `Space`
- **장전**: `R`
- **무기 교체**: `1` (라이플), `2` (샷건), `3` (수류탄)

#### 모바일 (가로 화면 권장)
- **이동**: 화면 좌측 가상 조이스틱
- **조준**: 화면 우측 터치 드래그
- **사격 / 점프 / 장전**: 화면 우측 가상 버튼
- **무기 교체**: 화면 상단 `1`, `2`, `3` 칩 터치
