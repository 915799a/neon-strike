# NEON STRIKE v4 (Mobile Portrait & Tactical Edition) 🔫
Three.js 기반의 3D 사이버펑크/SF FPS 게임

## 📱 v4 세로 모드(Portrait) 최적화 업데이트
1. **화면 방향 강제 잠금 해제**: 가로/세로 어느 쪽으로 폰을 들어도 자연스럽게 자동 전환 및 플레이 가능
2. **동적 시야각(FOV) 보정**: 세로 모드 시 카메라 시야각을 88도로 자동 확장하여 좁거나 답답하지 않고 쾌적한 시야 확보
3. **세로 맞춤형 HUD 레이아웃**: 상단에 점수/미니맵과 컴팩트 체력바, 무기 선택 칩을 깔끔하게 배치하여 하단 조작부와 간섭 분리
4. **인체공학적 터치 버튼 배치**:
   - 화면 좌측 하단 45% 영역 어디든 누르면 가상 조이스틱 즉시 생성
   - 상단 및 우측 넓은 영역에서 끊김 없는 360도 스와이프 조준
   - 우하단 엄지 동선에 맞춘 아치형 액션 버튼 (FIRE, JUMP, RELOAD, ZOOM)
5. **반응형 메뉴**: 로비, 무기 보관함, 설정 화면이 세로 화면에서도 스크롤 없이 한눈에 들어오도록 패딩/크기 최적화

## 🎨 v3 비주얼 디자인 (눈 편한 에디션 유지)
- 차분한 딥 네이비, 슬레이트 그레이, 소프트 민트/스틸블루 컬러 팔레트
- 원경 네이비 안개(Fog) 및 은은한 매트 콘크리트 패널 바닥
- 세련된 반투명 다크 글래스모피즘 미니멀 UI

## 🎮 주요 게임 시스템
- **로비 화면 & 설정**: 조준 감도 슬라이더, BGM/SFX 볼륨, 음소거, 최고 기록 저장
- **무기 해금 시스템**:
  - 1번 라이플 (기본)
  - 2번 샷건 (웨이브 3 달성 시 해금)
  - 3번 수류탄 (웨이브 5 달성 시 해금)
  - 4번 저격총 (웨이브 7 달성 시 해금, 우클릭/ZOOM 버튼으로 조준경 확대)
- **밸런스**: 플레이어 체력 150, 적 공격력 및 탄속 완화, 웨이브 클리어 시 체력 회복

## 🕹️ 조작법
### PC
- **이동**: `W`, `A`, `S`, `D`
- **조준**: 마우스 이동 (클릭 시 마우스 고정)
- **발사**: 마우스 좌클릭
- **조준경(저격총)**: 마우스 우클릭 유지
- **점프**: `Space`
- **장전**: `R`
- **무기 교체**: `1`, `2`, `3`, `4`

### 모바일 (가로 / 세로 화면 모두 완벽 지원)
- **이동**: 화면 좌하단 가상 조이스틱
- **조준**: 화면 우측 / 상단 터치 드래그
- **사격 / 점프 / 장전 / ZOOM**: 우하단 터치 액션 버튼
- **무기 교체**: 화면 상단 무기 버튼
