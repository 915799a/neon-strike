# NEON STRIKE v5 (Headshot & Dash Edition) 🔫
Three.js 기반의 3D 사이버펑크/SF FPS 게임

## 💥 v5 핵심 업데이트
1. **헤드샷 즉사(One-shot Headshot Kill) 시스템**:
   - 로봇 머리 피격 시 남은 체력과 상관없이 즉시 원샷원킬! (라이플, 샷건, 저격총 모두 적용)
   - 굵은 붉은색 히트마커(X) 점멸 및 화면 중앙에 "HEADSHOT! +100" 플로팅 텍스트 팝업
   - 묵직한 저음과 높은 핑이 교차하는 전용 헤드샷 크리티컬 사운드
   - 헤드샷 처치 보너스 점수 (+100점 추가)
2. **긴급 회피 대시(Dash) 스킬**:
   - 순간적으로 빠르게 이동 방향으로 치고 나가는 고속 대시 회피기 (0.4초 무적 판정)
   - PC: `Shift` 키 / 모바일: 우하단 `DASH` 터치 버튼
   - 쿨다운 3초: HUD 및 터치 버튼에 DASH 충전 게이지 시각화
3. **적 처치 시 보급 아이템 팩 드랍**:
   - 적 처치 시 35% 확률로 바닥에 회전하는 큐브 아이템 드랍
   - 초록색 메디킷: 획득 시 체력 +35 즉시 회복
   - 파란색 앰모킷: 모든 무기 탄약 완충 및 수류탄 +1
   - 가까이 접근하면 자동 획득 및 획득 사운드/알림
4. **HUD 간섭 개선**: 가로 모드에서 탄약 표시가 점프 버튼과 겹치던 레이아웃 추가 보정

## 📱 v4 세로 모드(Portrait) 최적화
- **화면 방향 강제 잠금 해제**: 가로/세로 어느 쪽으로 폰을 들어도 자연스럽게 자동 전환 및 플레이 가능
- **동적 시야각(FOV) 보정**: 세로 모드 시 카메라 시야각을 88도로 자동 확장하여 쾌적한 시야 확보
- **세로 맞춤형 HUD 레이아웃**: 상단에 점수/미니맵과 컴팩트 체력바, 무기 선택 칩 배치

## 🎨 v3 비주얼 디자인 (눈 편한 에디션 유지)
- 차분한 딥 네이비, 슬레이트 그레이, 소프트 민트/스틸블루 컬러 팔레트
- 원경 네이비 안개(Fog) 및 은은한 매트 콘크리트 패널 바닥
- 세련된 반투명 다크 글래스모피즘 미니멀 UI

## 🎮 주요 게임 시스템
- **로비 화면 & 설정**: 조준 감도 슬라이더, BGM/SFX 볼륨, 음소거, 최고 기록 저장
- **무기 해금 시스템**:
  - 1번 라이플 (기본)
  - 2번 샷건 (웨이브 3 달성 시 해금)
  - 3번 수류탄 (웨이브 5 달성 시 해금)
  - 4번 저격총 (웨이브 7 달성 시 해금, 우클릭/ZOOM 버튼으로 조준경 확대)
- **밸런스**: 플레이어 체력 150, 적 공격력 및 탄속 완화, 웨이브 클리어 시 체력 회복

## 🕹️ 조작법
### PC
- **이동**: `W`, `A`, `S`, `D`
- **조준**: 마우스 이동 (클릭 시 마우스 고정)
- **발사**: 마우스 좌클릭
- **대시(회피)**: `Shift`
- **조준경(저격총)**: 마우스 우클릭 유지
- **점프**: `Space`
- **장전**: `R`
- **무기 교체**: `1`, `2`, `3`, `4`

### 모바일 (가로 / 세로 화면 모두 완벽 지원)
- **이동**: 화면 좌하단 가상 조이스틱
- **조준**: 화면 우측 / 상단 터치 드래그
- **사격 / 대시 / 점프 / 장전 / ZOOM**: 우하단 터치 액션 버튼
- **무기 교체**: 화면 상단 무기 버튼
