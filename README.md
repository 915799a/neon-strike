# NEON STRIKE v2 🔫
Three.js 기반의 3D 사이버펑크 네온 FPS 게임

## 🎮 v2 신규 업데이트 내용
1. **로비(메인 메뉴) 추가**: 시작 화면, 무기 보관함, 설정 메뉴, 최고 기록 표시
2. **설정 메뉴**: 조준 감도(마우스/터치), BGM 볼륨, 효과음 볼륨, 음소거 토글
3. **무기 해금 시스템**:
   - 1번 라이플 (기본)
   - 2번 샷건 (웨이브 3 달성 시 해금)
   - 3번 수류탄 (웨이브 5 달성 시 해금)
   - 4번 저격총 (웨이브 7 달성 시 해금, 우클릭/ZOOM 버튼으로 조준경 확대)
4. **난이도 완화 (밸런스 패치)**:
   - 플레이어 기본 체력 150 상향
   - 적 공격력 감소 및 사격 딜레이 증가
   - 웨이브 클리어 시 체력 회복량 증가 (+60)

## 🕹️ 조작법
### PC
- **이동**: `W`, `A`, `S`, `D`
- **조준**: 마우스 이동 (클릭 시 마우스 고정)
- **발사**: 마우스 좌클릭
- **조준경(저격총)**: 마우스 우클릭 유지
- **점프**: `Space`
- **장전**: `R`
- **무기 교체**: `1`, `2`, `3`, `4`

### 모바일 (가로 화면 권장)
- **이동**: 화면 좌측 가상 조이스틱
- **조준**: 화면 우측 터치 드래그
- **사격 / 점프 / 장전 / ZOOM**: 화면 우측 가상 버튼
- **무기 교체**: 화면 상단 무기 버튼
